# v2.4.2 — the audit findings closed

Four agents audited the docs, every command, the state machine and a first-owner journey. All reproduced findings are fixed, each test-first.

- **Gates mean the owner's go** — a change request with an approval word no longer opens a gate; skip/reopen/force are guarded; `dh next` shows drift.
- **Verify cannot be skipped green** — a skipped blocking row keeps the report red; stale verify and smoke are refused.
- **The CLI always answers in JSON** — usage errors, `--help`, bad `--project`, empty folders (`NO_RUN`), corrupt state; ten parallel writers keep all their keys.
- **No secrets or personal paths on disk** — one scrubber across notes, board, brief, pending, research, lessons, RESUME and HANDOFF.
- **Sites come out right** — the owner's hero text is kept, vendor logos and placeholder images block review, hreflang works for `/en` sites, the scaffold typechecks.
- **Docs tell the truth** — counts, atlas and a generated flags reference are tested.
