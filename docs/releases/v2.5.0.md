# v2.5.0 — every path holds together, and the harness itself keeps deckhand honest

- **Auto mode never goes live alone:** G4 waits for your own words in every mode.
- **Bring your existing app:** the plan starts from the pages it already has (`dh plan init --from-app`); only what changes becomes work.
- **Your brand before you look:** the app you test at G2 already carries your name and colours.
- **No late surprise:** the server and domain you will need are in PENDING the moment define closes.
- **Client projects:** the client approves each gate, and the handoff transfers the repo, domain, server and secrets.
- **Hooks in 6 harnesses:** `dh harness install` — the harness blocks hand-edited deckhand state, an early deploying push and secrets in clear, and logs every command for `dh autopsy`.
- **Skills:** `dh next` names the installed agent skills that help the current phase.
