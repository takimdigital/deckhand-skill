# v2.4.0 — the field-test findings closed, harness lines as data, a try-on playground

- **Build tells the truth.** `dh phase done build` checks every planned page and form, and the default compose starts with a navbar.
- **No demo copy ships.** Demo prices, `href="#"` links and empty `<Hero />` usages are flagged; `seo apply` fixes a wrong `<html lang>`.
- **Clone is safer.** A base's NOTICE is kept as it was, ignored files stay out, and a missing LICENSE is warned about.
- **Hermes, Gemini CLI and OpenCode get their own instructions.** Harness lines are data with a fallback; on Hermes, bots run as no-agent cron jobs and `todo_list` tracks a workflow.
- **Try-on fits are checked for every kind of section.** All 1,247 catalog designs have a verdict; Keep, Discard and export binding bugs found in a real browser are fixed.
- **A clean machine.** New `dh clean` (a dry run first) removes only Deckhand's own leftovers; its tests and `autopsy` no longer leave temp folders behind.
- **A saved test site.** `playground/` restores a ready try-on site in one command.
- **Isolation and project detection.** A test home never reads your real keys, and a stray `package.json` in your home folder is never taken for a project.
- **All 23 findings of the 2026-09-29 field test are closed**, each with a test.
