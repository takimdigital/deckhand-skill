# CLI flags — every option of every command

Generated by `scripts/gen_cli_flags.py` from the real parser (do not edit; `py scripts/gen_cli_flags.py` rewrites it, a test keeps it current). Every command also takes `--project DIR`. Where the parser has no help text the meaning is read from the code. `dh <command> --help` lists the positional actions. `dh tryon` passes through to the try-on engine (`references/50-tryon.md`).

| command | flag | meaning |
|---|---|---|
| `dh init` | `--name NAME` | name of the project / library entry |
|  | `--mode {phased|auto}` | phased (the run stops at the gates) or auto |
|  | `--path {pool|mine|existing|scratch}` | how the base is chosen |
|  | `--for {me|client}` | client: this project keeps its own settings and secrets |
| `dh resume` | `--check` | re-prove every claim against reality |
|  | `--online` | also probe the network |
|  | `--hook` | SessionStart hook: plain text, nothing outside a deckhand project |
|  | `--install-hook {claude}` | add the SessionStart hook to Claude Code's user settings |
| `dh hook` | `--harness HARNESS` | harness to match |
| `dh harness` | `--harness HARNESS` | harness to match |
|  | `--dry` | show what would change, write nothing |
| `dh phase` | `--reason REASON` | why (recorded with the change) |
|  | `--force FORCE` | record done despite a red check; needs a reason (--force "why" or --reason), kept and shown |
| `dh gate` | `--note NOTE` | free-text note |
|  | `--quote QUOTE` | the owner's own words, verbatim (required in phased mode; a change request re-opens instead) |
| `dh reopen` | `--reason REASON` | why (recorded with the change) |
| `dh profile` | `--here` | this project's own layer (.deckhand/, gitignored) |
|  | `--machine` | ~/.deckhand (every project) |
|  | `--offline` | no network probes |
|  | `--set here|machine|FOLDER` | where: where this project keeps its settings and keys (remembered) |
| `dh vault` | `--here` | this project's own layer (.deckhand/, gitignored) |
|  | `--machine` | ~/.deckhand (every project) |
| `dh pending` | `--why WHY` | why: what it unblocks (pending add) · why a step was done or skipped (workflow step) |
|  | `--how HOW` | exact steps for the owner |
|  | `--where WHERE` | where the owner does it |
|  | `--when WHEN` | defer until a phase/gate trigger |
|  | `--rec REC` | your recommendation for the decision |
|  | `--reason REASON` | why (recorded with the change) |
|  | `--for-project FOR_PROJECT` | machine item that powers one project |
|  | `--machine` | ~/.deckhand/pending.md: the owner's own cross-project items |
|  | `--all` | list: include deferred (when:) and nag: no items |
| `dh pool` | `--shape SHAPE` | site shape to match |
|  | `--features FEATURES` | comma-separated features to match |
|  | `--languages LANGUAGES` | comma-separated site languages to match |
|  | `--top TOP` | how many results to return |
|  | `--mine` | the owner's own library instead of the shared pool |
|  | `--lane LANE` | pool lane to match (default web); a base of another lane is refused |
| `dh plan` | `--agents AGENTS` | how many parallel work packages to split the plan into |
|  | `--force` | override the guard |
|  | `--from-app` | path=existing: start the sitemap from the routes the app already serves |
| `dh bb` | `--wp WP` | work package id (default all) |
|  | `--kind KIND` | entry kind (bb) · source kind (research) |
|  | `--msg MSG` | the message text |
|  | `--last LAST` | how many latest entries to read (default 40) |
|  | `--max MAX` | seconds to wait (default 170) |
| `dh clone` | `--to TO` | destination folder |
|  | `--no-install` | skip the dependency install |
| `dh adopt` | `--to TO` | destination folder |
|  | `--install` | run the dependency install |
| `dh scaffold` | `--to TO` | destination folder |
|  | `--pm {npm|pnpm|bun|yarn}` | package manager for the scaffold (default npm) |
| `dh compose` | `--page PAGE` | page file to compose (default app/page.tsx) |
|  | `--sections SECTIONS` | comma-separated sections (default navbar,hero,features,pricing,faq,cta,footer) |
|  | `--copy COPY` | copy.json holding the page's words |
| `dh dev` | `--port PORT` | dev-server port |
|  | `--from FROM_PORT` | port: the first port to try |
|  | `--cmd SVC_CMD` | add: the command that starts the service |
|  | `--ready READY` | add: regex of the log line that says it is up |
|  | `--env-file ENV_FILE` | add: KEY=VALUE file loaded into the service's environment (e.g. .env) |
| `dh suggest` | `--all` | every suggestion, dismissed ones included |
|  | `--days DAYS` | dismiss for 1..365 days |
| `dh workflow` | `--deliverable DELIVERABLE` | brief.deliverable to match |
|  | `--industry INDUSTRY` | industry to match |
|  | `--shape SHAPE` | site shape to match |
|  | `--features FEATURES` | comma-separated features to match |
|  | `--harness HARNESS` | harness to match |
|  | `--os OS` | operating system to match |
|  | `--why WHY` | why: what it unblocks (pending add) · why a step was done or skipped (workflow step) |
|  | `--id ID` | workflow id |
|  | `--title TITLE` | workflow title |
|  | `--phase PHASE` | phase the entry belongs to |
|  | `--min-level {draft|proven|trusted}` | — |
|  | `--top TOP` | how many results to return |
|  | `--refresh` | re-read the source instead of the cache |
|  | `--accept` | use: the owner saw the non-dh commands and said OK |
|  | `--set SET` | use: a param, name=value (repeatable) |
|  | `--format {json|md}` | — |
|  | `--from-run` | extract the workflow from this run |
|  | `--from-autopsy FROM_AUTOPSY` | save: the workflow autopsy id whose proposals to apply |
|  | `--proposals PROPOSALS` | save: P1,P3 (the ones the owner accepted) |
|  | `--public` | save: a bundle for the community pool (a PR), not your own pool |
| `dh base` | `--kind {scratch|existing|template}` | entry kind (bb) · source kind (research) |
|  | `--note NOTE` | free-text note |
|  | `--source SOURCE` | where the base came from |
| `dh rebrand` | `--dry` | show what would change, write nothing |
|  | `--allow ALLOW` | comma-separated names to allow |
| `dh slop` | `--text TEXT` | the text itself, or - for stdin |
|  | `--url URL` | read the rendered pages of any site |
|  | `--lang LANG` | en, fr, es… (default: brief.languages, else detected per text) |
|  | `--buzz` | add: a weaker word (use sparingly), not a strong tell |
|  | `--phrase` | add: a multi-word phrase, not a single word |
|  | `--fix FIX` | add: the plainer word to use instead |
| `dh verify` | `--url URL` | check this site (live or running) instead of the local build |
|  | `--skip SKIP` | comma-separated check rows NOT to run |
|  | `--allow ALLOW` | comma-separated names to allow |
|  | `--reason REASON` | why rows are skipped (recorded; without it a skipped blocking row keeps the report red) |
| `dh deploy` | `--app APP` | Coolify application UUID |
|  | `--url URL` | check this site (live or running) instead of the local build |
|  | `--force` | override the guard |
| `dh ops` | `--runner RUNNER` | github \| cron \| local \| hermes (default: hermes inside a Hermes session, else github) |
| `dh learn` | `--phase PHASE` | phase the entry belongs to |
|  | `--symptom SYMPTOM` | what went wrong, as seen |
|  | `--cause CAUSE` | the root cause |
|  | `--fix FIX` | the proven fix |
|  | `--signature SIGNATURE` | regex that recognizes the error (default: the symptom, escaped) |
|  | `--command COMMAND` | the command the lesson applies to |
|  | `--rung RUNG` | rung of the lesson (default pitfall; evidence only moves it up) |
|  | `--scope SCOPE` | global (~/.deckhand, default) or project (.deckhand/lessons.jsonl) |
|  | `--log LOG` | path of a log file to read |
|  | `--text TEXT` | the text / error text itself |
|  | `--stack STACK` | comma-separated stacks the lesson applies to |
| `dh run` | `--phase PHASE` | phase the entry belongs to |
|  | `--fix` | replay a proven auto-safe recipe, retry once |
| `dh autopsy` | `--latest` | read the latest session |
|  | `--apply` | write the result (default: dry run) |
|  | `--session SESSION` | a Hermes session id (state.db); default: HERMES_SESSION_ID, else the latest in this project |
|  | `--workflow` | the workflow autopsy: timeline, questions asked + answers, deviations, cost, proposals |
|  | `--part PART` | with --workflow: only one section (timeline\|questions\|deviations\|errors\|delegation\|guidance\|proposals) |
| `dh harvest` | `--name NAME` | name of the project / library entry |
|  | `--to TO` | destination folder |

|  | `--public` | public, not private |
|  | `--push` | secret scan, then a private repo on your GitHub + your library index |
